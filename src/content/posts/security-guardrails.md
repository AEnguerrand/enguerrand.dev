## Start with a concrete problem

- Which failure or risk did the team need to address?
- What constraints shaped the work?

## Design a useful control

- Where did you put the control in the workflow?
- What feedback did a developer receive?
- How did you handle exceptions?

## Check the result

- Which checks or observations support your conclusion?
- What did those checks fail to prove?
- Remove confidential details from examples and logs.

## What you would change

- Which trade-off remains?
- What is one small next step?
