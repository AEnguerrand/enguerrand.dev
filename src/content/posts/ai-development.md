## Choose a bounded task

- What did you ask an AI tool to do?
- Which context did it need, and which data did you keep private?

## Review the output

- Which changes were useful?
- Which assumptions needed correction?
- What did human review add?

## Test the result

- Which tests or manual checks did you run?
- What evidence can you show?
- Which parts remain unverified?

## Improve the workflow

- What would you repeat?
- What would you change next time?
- Avoid broad productivity claims unless you have data to support them.
